Maji Ndogo Agriculture Analytics & Validation Pipeline

Building confidence in agricultural insights by validating field surveys against environmental measurements.

The challenge

Agricultural modeling is only as dependable as its source data. This project brings relational, CSV, field-survey, and weather-station data into one reproducible workflow and checks for inconsistencies before analysis.

The approach

I used modular Python processors for cleaning and transformation, automated pytest checks for schema and value rules, and two-tailed hypothesis tests to compare temperature, rainfall, and pollution measurements.

IMDB Review Sentiment Analysis

Classifying audience sentiment from 50,000 real-world movie reviews.

The challenge

Turn unstructured review text into a dependable positive-or-negative prediction while establishing a clear, repeatable evaluation workflow.

The approach

I cleaned and tokenized text, generated 1,000 TF-IDF features, split the data 80/20, and trained a logistic regression classifier. Performance was checked using accuracy, precision, recall, F1, and a confusion matrix.

TMDB Film Genre Prediction

Exploring how movie metadata can predict a film's primary genre.

The challenge

Prepare mixed numeric and categorical movie metadata for multiclass prediction while reducing the impact of sparse genre classes.

The approach

I cleaned missing values, encoded categorical variables, scaled numeric features, and created 70/15/15 train, development, and test sets. KNN and multinomial logistic regression were compared using accuracy, recall, and weighted F1.
