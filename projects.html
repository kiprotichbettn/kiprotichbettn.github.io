IMDB Sentiment Classification System

A reproducible NLP classification pipeline trained and evaluated on unique IMDB review text.

The challenge

Build a dependable positive-or-negative review classifier without allowing duplicate text or preprocessing decisions to leak information into evaluation.

The approach

I removed 418 duplicate review texts from the 50,000 original reviews, leaving 49,582 unique reviews. I then used a stratified 80/20 train-test split and a leakage-safe scikit-learn Pipeline combining TF-IDF preprocessing with model training. Model comparison used cross-validation on training data only, and the selected logistic regression pipeline was evaluated once on the untouched test data.

90.80%test accuracy
90.80%weighted F1-score
49,582unique reviews used

Test results

The final model correctly classified 4,450 negative reviews and 4,555 positive reviews, with 491 false positives and 421 false negatives.

Delivery

Error analysis documented where the classifier failed. The complete fitted model pipeline was saved for reproducible inference and connected to a Streamlit prediction interface.

Maji Ndogo Agriculture Analytics & Validation Pipeline

Building confidence in agricultural insights by validating field surveys against environmental measurements.

The challenge

Agricultural modeling is only as dependable as its source data. This project brings relational, CSV, field-survey, and weather-station data into one reproducible workflow and checks for inconsistencies before analysis.

The approach

I used modular Python processors for cleaning and transformation, automated pytest checks for schema and value rules, and two-tailed hypothesis tests to compare temperature, rainfall, and pollution measurements.

TMDB Film Genre Prediction

Exploring how movie metadata can predict a film's primary genre.

The challenge

Prepare mixed numeric and categorical movie metadata for multiclass prediction while reducing the impact of sparse genre classes.

The approach

I cleaned missing values, encoded categorical variables, scaled numeric features, and created 70/15/15 train, development, and test sets. KNN and multinomial logistic regression were compared using accuracy, recall, and weighted F1.
