## Run locally

The site has no installation step. Open `index.html` directly in a browser, or run a local static server from the repository directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The portfolio is deployed through GitHub Pages from this repository's `main` branch. Because it is a static site, publishing changes only requires committing and pushing the updated HTML and CSS files.
